# Shell & iTerm2 高频速查表（终端敲 `hh` 查看）

> 提示：在速查界面按 `/` 搜索、`j/k` 翻页、`q` 退出；在 Vim 中敲 `:hh`（或 `\?`）查看 Vim 速查表。

---

## 一、Zsh 命令行光标与编辑（原生神技）

| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + a` / `Ctrl + e` | 跳到命令行行首 / 行尾 |
| `Ctrl + u` / `Ctrl + k` | 删除光标前全部内容 / 删除光标后全部内容 |
| `Ctrl + w` | 删除光标前一个单词 |
| `Ctrl + y` | 粘贴刚才用 `Ctrl+u/k/w` 删掉的内容 |
| `Ctrl + _` | 撤销刚才的命令行编辑 |
| `Ctrl + r` | 反向搜索历史命令（继续按 `Ctrl + r` 切上一条） |
| `Ctrl + l` | 清屏（等价于 `clear`） |
| `Ctrl + c` / `Ctrl + d` | 中断当前命令 / 退出当前终端会话 |

## 二、Zsh & macOS 效率命令（每天都在用）

| 命令 | 说明 |
| :--- | :--- |
| `cd -` | 在最近两个目录之间一键来回切换 |
| `!!` | 重复执行上一条命令（如 `sudo !!`） |
| `!$` | 复用上一条命令的最后一个参数（如 `mkdir foo && cd !$`） |
| `open .` | 用 Finder 打开当前目录 |
| `pbcopy` / `pbpaste` | 管道写入 / 读出 macOS 剪贴板（如 `cat a.txt \| pbcopy`） |
| `hh` | 打开本 Shell & iTerm2 速查表 |

## 三、Zsh 插件快捷键（按插件分类）

### 1. zsh-autosuggestions（历史自动补全）
| 快捷键 | 说明 |
| :--- | :--- |
| `→`（右方向键） | 采纳整条灰色历史命令建议 |

### 2. sudo（一键提权）
| 快捷键 | 说明 |
| :--- | :--- |
| `Esc` 连按两下 | 在当前命令最前面自动补 `sudo` |

### 3. autojump（目录快速跳转）
| 命令 | 说明 |
| :--- | :--- |
| `j <关键词>` | 跳转到权重最高的匹配目录 |
| `jc <关键词>` | 跳转到当前目录的子目录 |
| `jo <关键词>` | 在 Finder 中打开匹配目录 |
| `j -s` | 查看已记录的目录权重统计 |

### 4. git（Oh My Zsh 内置高频短命令）
| 命令 | 说明 |
| :--- | :--- |
| `gst` / `gd` | `git status` / `git diff` |
| `gaa` / `gcmsg "说明"` | `git add --all` / `git commit -m "说明"` |
| `gp` / `gl` | `git push` / `git pull` |
| `gco <分支>` / `gcb <新分支>` | 切换分支 / 新建并切换分支 |
| `gsta` / `gstp` | 暂存当前改动（`stash`）/ 恢复暂存（`stash pop`） |
| `glog` | 图形化查看精简提交历史 |

## 四、iTerm2 窗口与分屏快捷键

| 快捷键 | 说明 |
| :--- | :--- |
| `⌘ + t` / `⌘ + w` | 新建标签页 / 关闭当前分屏或标签页 |
| `⌘ + 1` ~ `⌘ + 9` | 快速切换到第 N 个标签页 |
| `⌘ + d` / `⌘ + Shift + d` | 左右分屏 / 上下分屏 |
| `⌘ + [` / `⌘ + ]` | 在分屏之间顺序切换焦点 |
| `⌘ + Option + 方向键` | 按上下左右方向精准切换分屏 |
| `⌘ + Shift + Enter` | 临时最大化 / 还原当前分屏（看日志/改代码超好用） |
| `⌘ + u` | 一键临时开关背景透明 |
| `⌘ + k` | 彻底清空当前屏幕缓冲区 |
| `⌘ + f` | 在终端输出历史中搜索关键词 |
| `⌘ + Shift + h` | 查看 iTerm2 剪贴板历史 |
| `⌘ + +` / `⌘ + -` / `⌘ + 0` | 放大字体 / 缩小字体 / 恢复默认字号 |
