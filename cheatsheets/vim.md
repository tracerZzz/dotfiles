# Vim 高频速查表（敲 `:hh` 或 `\?` 打开，按 `q` 关闭）

> 提示：`<leader>` 默认为反斜杠 `\`；可直接按 `/` 搜索关键词，按 `q` 立刻关闭本窗口。

---

## 一、Vim 核心快捷键

### 1. 移动与跳转
| 快捷键 | 说明 |
| :--- | :--- |
| `h / j / k / l` | 左 / 下 / 上 / 右 |
| `w` / `b` / `e` | 下一个词首 / 上一个词首 / 当前词尾 |
| `0` / `^` / `$` | 行首 / 首个非空字符 / 行尾 |
| `f<字符>` / `t<字符>` | 行内跳到下一个指定字符上 / 前一位（`;` 继续，`,` 反向） |
| `gg` / `G` | 文件第一行 / 最后一行 |
| `:行号` 或 `行号G` | 跳转到指定行（如 `:42`） |
| `H` / `M` / `L` | 跳到当前屏幕顶部 / 中间 / 底部 |
| `{` / `}` | 按空行向上 / 向下跳段落 |
| `Ctrl + u` / `Ctrl + d` | 向上 / 向下翻半页 |
| `zz` | 将当前行滚到屏幕正中央 |
| `Ctrl + o` / `Ctrl + i` | 跳回上一个位置 / 前进到下一个位置 |
| `''`（两个单引号） | 在最近两个跳转位置间来回切换 |
| `%` | 在成对括号 `()` `{}` `[]` 间跳转 |
| `gd` | 跳转到当前文件内局部变量的定义处 |

### 2. 编辑、文本对象与多行操作
| 快捷键 | 说明 |
| :--- | :--- |
| `i` / `a` / `I` / `A` | 光标前 / 光标后 / 行首 / 行尾进入插入模式 |
| `o` / `O` | 下一行插入 / 上一行插入 |
| `x` / `dd` / `D` | 删字符 / 删整行 / 删到行尾 |
| `C` / `cc` | 改到行尾 / 清空整行并进入插入模式 |
| `dw` / `ciw` / `yiw` | 删当前词 / 改当前词 / 复制当前词 |
| `ci"` / `ci(` / `ci{` | 清空引号或括号内内容并进入插入模式（`di"` 只删不插入） |
| `cit` / `dit` | 改 / 删 HTML 或 XML 标签内部内容 |
| `vip` | 快速选中当前整个段落 |
| `yy` / `p` / `P` | 复制整行 / 粘贴到下方 / 粘贴到上方 |
| `>>` / `<<` / `=` | 增加缩进 / 减少缩进 / 自动对齐缩进（选中后按 `=`） |
| `J` / `~` | 合并下一行到行尾 / 切换光标字符大小写 |
| `Ctrl + a` / `Ctrl + x` | 光标处数字加 1 / 减 1 |
| `u` / `Ctrl + r` | 撤销 / 重做 |
| `.` | 重复上一次编辑操作（Vim 最强效率键） |
| `v` / `V` / `Ctrl + v` | 字符选中 / 整行选中 / 列块选中 |
| `Ctrl+v` → 选中 → `I` → `Esc` | 多行行首同时插入相同文字（列编辑神技） |
| `qa` ... `q` → `@a` | 录制宏到寄存器 `a` 并回放（`@@` 重复上次宏） |

### 3. 搜索与替换
| 快捷键 | 说明 |
| :--- | :--- |
| `/关键词` / `?关键词` | 向下搜索 / 向上搜索 |
| `n` / `N` | 下一个 / 上一个匹配项 |
| `*` / `#` | 向下 / 向上搜索光标所在的整个单词 |
| `:noh` | 取消当前搜索高亮 |
| `:%s/旧/新/gc` | 全文逐个确认替换（去掉 `c` 直接全部替换） |

### 4. 分屏、Buffer 与保存退出
| 快捷键 | 说明 |
| :--- | :--- |
| `:vsp 文件` / `:sp 文件` | 左右分屏 / 上下分屏打开文件 |
| `Ctrl + w` + `h/j/k/l` | 在不同分屏窗口（含目录树）间切换焦点 |
| `Ctrl + w` + `=` | 所有分屏均分宽度 |
| `Ctrl + w` + `c` / `o` | 关闭当前分屏 / 只保留当前分屏 |
| `:bn` / `:bp` / `:bd` | 切下一个 Buffer / 上一个 Buffer / 关闭当前 Buffer |
| `:w` / `:q` / `:wq` | 保存 / 退出 / 保存并退出 |
| `:q!` / `:qa!` | 强制不保存退出当前窗口 / 全部退出 |
| `:hh` 或 `\?` | 打开本 Vim 速查表（按 `q` 关闭） |

## 二、Vim 插件快捷键（按插件分类）

### 1. NERDTree（左侧文件目录树）
**全局触发：**
| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + t` | 开关目录树（最常用） |
| `Ctrl + f` | 在目录树中定位当前打开的文件 |
| `Ctrl + n` | 打开目录树 |
| `\n` | 将光标焦点切回目录树 |

**在目录树窗口内操作：**
| 快捷键 | 说明 |
| :--- | :--- |
| `Enter` / `o` | 打开文件或展开/折叠目录 |
| `s` / `i` | 左右分屏 / 上下分屏打开文件 |
| `m` | 文件操作菜单（新建 `a`、移动/重命名 `m`、删除 `d`） |
| `r` / `R` | 刷新当前目录 / 刷新根目录 |
| `I`（大写 i） | 显示/隐藏点文件（如 `.zshrc`、`.gitignore`） |

### 2. fzf.vim（模糊搜索）
**全局触发：**
| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + p` | 模糊搜索当前项目文件（`:Files`） |
| `\f` | 全局搜索文件内容（`:Rg`，需安装 `ripgrep`） |
| `\b` | 在已打开的 Buffer 之间快速切换（`:Buffers`） |

**在搜索弹窗内操作：**
| 快捷键 | 说明 |
| :--- | :--- |
| `Enter` | 当前窗口打开选中项 |
| `Ctrl + v` / `Ctrl + x` | 左右分屏 / 上下分屏打开选中项 |
| `Esc` / `Ctrl + c` | 关闭搜索弹窗 |

### 3. vim-commentary（快速注释）
| 快捷键 | 说明 |
| :--- | :--- |
| `gcc` | 注释 / 取消注释当前行 |
| `gc`（可视模式选中后） | 注释 / 取消注释选中的多行 |
| `gcap` | 注释 / 取消注释当前整段 |

### 4. vim-airline & onehalfdark
- 无需快捷键，自动提供底部状态栏与 `One Half Dark` 透明配色。
